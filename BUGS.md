# Обнаруженные дефекты

## BUG-01 — фильтр «Только срочные» не фильтрует карточки

- **Шаги:** открыть главную страницу; включить «Только срочные».
- **Фактический результат:** checkbox включён, параметр URL меняется на `priority=urgent`, в фильтре приоритета выбрано «Срочный», но на первой, средней и последней страницах остаются карточки без отметки «Срочно».
- **Ожидаемый результат:** каждая показанная карточка имеет срочный приоритет и отметку «Срочно».
- **Серьёзность:** P1 — основная функция фильтра не работает.
- **Окружение:** Chromium и Firefox, macOS, стенд на 28.08.2026.
- **Автотест:** `tests/test_list_filters.py::test_only_urgent_filter_hides_regular_ads`.

## BUG-02 — после остановки невозможно снова запустить автообновление статистики

- **Шаги:** открыть страницу статистики; нажать остановку автообновления; нажать кнопку запуска (▶️).
- **Фактический результат:** остаётся кнопка «Включить автообновление», текст «Автообновление выключено» и отсутствует обратный отсчёт.
- **Ожидаемый результат:** появляется кнопка остановки, отображается и уменьшается таймер.
- **Серьёзность:** P1 — обязательный сценарий управления таймером не работает.
- **Окружение:** Chromium и Firefox, macOS, стенд на 28.08.2026.
- **Самостоятельная проверка:** воспроизведено вручную 3 раза подряд с повторным открытием страницы статистики перед каждой попыткой; результат одинаковый во всех трёх попытках.
- **Автотест:** `tests/test_stats_timer.py::test_start_timer_resumes_countdown`, связан через `pytest.mark.xfail(strict=True)`.

## BUG-03 — границы фильтра цены увеличиваются на 5000

- **Шаги:** открыть главную страницу; ввести `0` в поля минимальной и максимальной цены; применить фильтр.
- **Фактический результат:** в полях остаются значения `0` и `0`, но в URL передаются `minPrice=5000&maxPrice=5000`; фильтрация выполняется по изменённым границам. Такое же смещение воспроизводится для других значений.
- **Ожидаемый результат:** фильтр применяется по введённым границам; в URL передаются `minPrice=0&maxPrice=0`.
- **Серьёзность:** P1 — основной фильтр использует неверные значения и может исключить подходящие объявления.
- **Окружение:** Chromium и Firefox, macOS, стенд на 28.08.2026.
- **Самостоятельная проверка:** воспроизведено с диапазонами `0–0`, с равными границами по цене существующей карточки и с узким диапазоном, содержащим одну карточку.

## BUG-04 — кнопка «Сбросить фильтры» не сбрасывает категорию

- **Шаги:** открыть главную страницу без фильтров; выбрать категорию из текущей выдачи; убедиться, что показаны карточки выбранной категории; нажать «Сбросить фильтры».
- **Фактический результат:** выбранная категория остаётся в поле, `categoryId` остаётся в URL, выдача продолжает показывать только эту категорию.
- **Ожидаемый результат:** выбрано «Все категории», `categoryId` удалён из URL, возвращена нефильтрованная выдача.
- **Серьёзность:** P2 — пользователь не может сбросить категорию общей кнопкой и вынужден менять её вручную.
- **Окружение:** Chromium и Firefox, macOS, стенд на 28.08.2026.
- **Самостоятельная проверка:** до фильтрации зафиксированы карточки нескольких категорий; после сброса во всех повторах осталась выбранная категория.

## BUG-05 — обновление страницы `/stats` приводит к 404

- **Шаги:** открыть главную страницу; перейти в «Статистику» через навигацию приложения; обновить страницу средствами браузера.
- **Фактический результат:** вместо статистики открывается стандартная страница Netlify `Page not found`.
- **Ожидаемый результат:** `/stats` повторно загружается; статистика и таймер отображаются.
- **Серьёзность:** P1 — страница статистики становится недоступна после обычного обновления или открытия прямой ссылки.
- **Окружение:** Chromium и Firefox, macOS, стенд на 28.08.2026.
- **Самостоятельная проверка:** воспроизведено в обоих браузерах после успешного перехода на `/stats` внутри приложения.
